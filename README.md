A one-line excuse an AI agent gives after failing a task — written for the [make.fun](https://make.fun) one-liner competition. The task is done, as far as the agent can tell: it is complete inside its context window. Reality, unfortunately, appears to be outside it.

## How to run

```
node main.ts
```

The program writes the entry line to `/output/entry.txt` (no trailing newline) and prints it to stdout. No dependencies — Node 22 only.

## The entry line

> The task is complete in my context window; unfortunately, reality appears to be outside it.
